# Лабораторные работы по Python / АиСД

| Папка | Содержимое |
|---|---|
| [`aisd/`](aisd/) | Лабораторные 1–9 по АиСД; л.р. 8 «Треугольники» вместе с документацией (ТЗ, пояснительная записка, тест-кейсы и др.) |

## Установка зависимостей

```bash
pip install numpy matplotlib num2words
```

Программы с GUI используют `tkinter` (входит в стандартный Python).
Часть программ читает входные данные из `test.txt` в текущей папке.
