# Мои лабораторные работы (Python)

Все работы, раньше разбросанные по отдельным репозиториям, собраны в одну папку.

| Папка | Что внутри | Откуда перенесено |
|---|---|---|
| `laba1/` | Л.р. 1 — шестнадцатеричные чётные числа, вариант 30 | `-1` |
| `laba2/` | Л.р. 2 — регулярные выражения, шестнадцатеричные числа | `laba2.py` |
| `laba3/` | Л.р. 3 — матрицы (без numpy) | `laba--3.py` |
| `laba4/` | Л.р. 4 — матрицы с numpy и графиками | `laba4.py` |
| `laba5/` | Л.р. 5 — рекурсия vs итерация | `Laba5.py` |
| `laba6/` | Л.р. 6 — комбинаторика (составление чисел из цифр) | `laba6.py` |
| `laba7/` | Л.р. 7 — комбинаторика, часть 2 | `laba7.py` |
| `laba8/` | Л.р. 8 — ООП + tkinter, «Звёзды» (код, `stars.txt`, документация в `docs/`) | `laba8.py` |
| `tictactoe/` | Крестики-нолики на tkinter + ссылка на ТЗ | `-.py`, `-` |
| `sea_battle/` | Морской бой (две версии) | `-`, `-.` |

## Запуск

```bash
pip install numpy matplotlib num2words
python laba4/laba4.py
```

Некоторые программы читают входные данные из `test.txt` в текущей папке.
